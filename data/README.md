# Data Directory

This directory contains malaria surveillance data for Uganda used in ensemble method complexity analysis.

## Directory Structure

```
data/
├── raw/                          # Original unprocessed data
│   ├── malaria_indicators_uga.csv    # WHO GHO malaria indicators (primary)
│   ├── Export_Malaria_Admissions_(Reported).csv
│   └── health_data_3_13_2026.csv
├── processed/                    # Cleaned and engineered features
│   ├── malaria_features_engineered.csv   # Final feature matrix for modeling
│   ├── who_indicators_clean.csv
│   ├── admissions_clean.csv
│   ├── health_data_clean.csv
│   └── feature_info.json
└── README.md
```

## Raw Data

### malaria_indicators_uga.csv (Primary Dataset)
- **Source**: WHO Global Health Observatory (GHO)
- **Rows**: 140 records
- **Columns**: 17 fields
- **Coverage**: Uganda malaria surveillance 2000-2024
- **Key Indicators**:
  - `MALARIA_EST_MORTALITY` - Estimated mortality rate per 100,000
  - `MALARIA_EST_INCIDENCE` - Incidence per 1,000 population at risk
  - `MALARIA_TOTAL_CASES` - Presumed + confirmed cases
  - `MALARIA_SUSPECTS` - Suspected cases
  - `MALARIA_INDIG` - Indigenous cases
  - `MALARIA_MICR_TEST` - Microscopy examinations
  - `MALARIA_MICR_POS` - Microscopy-positive cases

### Export_Malaria_Admissions_(Reported).csv
- **Source**: Uganda Health Data Observatory, Ministry of Health Uganda
- **URL**: https://nho.health.go.ug
- **Rows**: 164 records
- **Description**: Regional malaria admission reports

### health_data_3_13_2026.csv
- **Source**: Uganda Health Data Observatory, Ministry of Health Uganda
- **URL**: https://nho.health.go.ug
- **Rows**: 474 records
- **Description**: Supplementary health indicators

## Processed Data

### malaria_features_engineered.csv
- **Rows**: 129 samples (after cleaning/feature engineering)
- **Columns**: 23 (19 features + target + metadata)
- **Generated by**: `notebooks/02_feature_engineering.ipynb`

**Feature Categories**:
| Category | Features | Description |
|----------|----------|-------------|
| Temporal | `admissions_lag_1`, `admissions_lag_2` | 1-2 period lags |
| Rolling | `*_roll_mean_*`, `*_roll_std_*`, `*_roll_max_*` | 2-3 period windows |
| Change | `admissions_change`, `admissions_pct_change` | Absolute/percentage |
| Spatial | `region_encoded`, `region_mean`, `region_std` | Regional encoding |
| National | `national_mean`, `national_std`, `relative_to_national` | Country context |
| Target | `outbreak` | Binary classification (0/1) |
